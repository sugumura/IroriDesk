# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We want Irori Desk to be a welcoming project for everyone. Be respectful and constructive in issues, pull requests and discussions, and assume good intent.

## Reporting

If you experience or witness unacceptable behavior, please contact the maintainer, [@sugumura](https://github.com/sugumura), privately at **sugumura@gmail.com** instead of opening a public issue. All reports will be handled confidentially.
