# ロードマップ

[English](../ROADMAP.md) | 日本語

Irori Desk で予定していることを、おおよその順に並べています。予定は反響に合わせて変わります。ここにない機能が欲しいときや、早めてほしいものがあるときは、[Issue](https://github.com/sugumura/IroriDesk/issues) で教えてください。

Irori Desk は、Firestore と Firebase Authentication に対して **読み取り専用** のままです。書き込みを伴う機能（たとえば Emulator への書き込み）を入れるときは、はっきり分かる形で別に用意します。

## 次に取り組むこと

- **winget**：Windows で `winget install sugumura.IroriDesk` でインストールできるようにする。
- **クエリの強化**
  - `OR` 条件
  - 結果の続きを読み込む（カーソルでのページ送り）
  - 合計と平均の集計
  - Query Explain：クエリで使われたインデックスと、読み取り件数（料金の目安）を表示する

## その後

- **環境どうしの比較**：2つの接続（たとえば本番とステージング）で、同じドキュメントやコレクションの違いを表示する。
- **Emulator へのコピー**：選んだドキュメントを、手元の Firebase Emulator にコピーしてデバッグに使う。書き込むのは Emulator だけです。
- **フィールドの統計**：コレクション全体での型、値の出現頻度、欠けているフィールドをアプリで表示する（MCP サーバーには `describe_collection` があります）。
- **セキュリティルール**：ルールを表示し、あるユーザー（UID）がドキュメントを読めるかを確かめる。
- **保存したクエリ**：クエリに名前を付けて保存し、書き出してチームで共有する。
